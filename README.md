# To-Do List

## About the Project
The To-Do List is a simple web application designed to help users organize their daily tasks and manage their time effectively. Users can add tasks, mark them as completed, and keep track of their activities through a clean and user-friendly interface.

## Features
- Add new tasks.
- Mark tasks as completed.
- Delete tasks when they are no longer needed.
- Simple and user-friendly interface.
- Helps organize daily activities.

## Technologies Used
- HTML
- CSS
- JavaScript
